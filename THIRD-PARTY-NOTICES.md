# Distribution audit

The shipped runtime uses first-party relative modules, browser Web Crypto/IndexedDB/storage APIs, and system fonts. No third-party JavaScript runtime library, font, copied snippet with a separate attribution, or archive is included in this checkout. Browser/operating-system runtimes and separately installed QA tools are not redistributed. Branding/icons/images and user data are excluded from MIT.

This is an inventory of identified shipping components, not a license grant for excluded material. Preserve each applicable notice when repackaging.
